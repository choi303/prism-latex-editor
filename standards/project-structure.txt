================================================================================
MODULE PATTERN (API)
================================================================================

Each feature module contains:

    feature.routes.ts       Fastify route handlers (HTTP layer)
    feature.service.ts      Business logic (no HTTP concerns)
    feature.prompt.ts       AI prompt builders (if applicable)

Routes handle:
    Request parsing and validation (Zod)
    HTTP status codes and response formatting
    Error catching and response mapping

Services handle:
    Database queries
    External API calls
    Business rules and transformations

================================================================================
ADDING NEW FEATURES
================================================================================

When adding a new API feature:
    1. Create module folder under apps/api/src/modules/
    2. Create routes file and service file
    3. Register routes in apps/api/src/app.ts
    4. Add Zod schemas for request validation

When adding a new page:
    1. Create folder under apps/web/src/app/
    2. Add page.tsx with the route component
    3. Add components under apps/web/src/components/

When adding shared types or utilities:
    1. Use packages/config/ for build configuration
    2. Use packages/ui/ for shared React components
